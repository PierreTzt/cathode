# MonSuivi — votre suivi de séries

## Démarrer l'appli
Double-cliquez sur **demarrer-monsuivi.bat**.
Votre navigateur s'ouvre sur l'appli. Pour l'arrêter, fermez la fenêtre noire.

## Première utilisation
Au tout premier lancement, l'appli s'installe et importe automatiquement
votre historique TV Time (cela peut prendre une minute). Les fois suivantes,
le démarrage est immédiat.

## Prérequis (une seule fois)
Node.js doit être installé : https://nodejs.org (choisir la version proposée,
puis « suivant » jusqu'au bout).

## Où sont mes données ?
Tout est stocké sur votre PC dans le fichier `data/monsuivi.db`. Rien n'est
envoyé sur Internet.
